# SEP Evidence Upload Tracker 2026

Staff tick off numeracy and reading evidence items once they have uploaded them to their team's folder.

- `index.html` – the page (single file)
- `data.json` – the 196 items taken from the 2026 SEP Numeracy and Reading trackers (52 numeracy course rows, 98 reading course rows, 46 whole-school items)

## Important
This copy is the source of the page published as a Claude artifact. Shared ticks (who ticked, when, notes, team folder links) are saved through Claude's artifact database, so they only work when the page is opened from the Claude artifact link. Opened from a file or GitHub Pages, it shows the list but cannot save ticks.

To refresh the items, rebuild `data.json` from the tracker workbooks (columns: id, goal N/R, kind course/whole, team, year, title, ht, demand, task, artefact, etype, due, why).
