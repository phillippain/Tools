Save your decisions to GitHub

With a GitHub access token, each decision is saved straight into the HSC Economics repository (the file worksheet-maker/bank/reviews.json), and the Worksheet Maker reads it when it opens. You set this up once on each computer.

  1. Open GitHub’s new fine-grained token page, signed in as phillippain.
  2. Name it Question review and pick an expiry (90 days is sensible).
  3. Under Repository access choose Only select repositories and pick HSC-Economics.
  4. Under Permissions, set Contents to Read and write. Nothing else is needed.
  5. Press Generate token, copy it and paste it here.

The token stays in this browser and is sent only to GitHub. It can change files in HSC-Economics, so treat it like a password. Every page on phillippain.github.io shares this browser storage.
